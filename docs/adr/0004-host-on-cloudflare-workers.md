# Host on Cloudflare Workers, D1 and R2

The app runs on Cloudflare's free tier: pages and server logic on Workers, data in a D1 database created with the EU jurisdiction, images in R2, and password-recovery email through Cloudflare's Email Service to the Family's verified recovery address. Of the free options researched (docs/research/free-tier-hosting.md), it is the only one that neither pauses nor deletes an idle database, and it covers the database, image storage, email and EU data location with one provider. The budget is €0 per month plus a domain (about €10 a year, needed to send email); if a free limit is ever hit (the app errors until midnight UTC rather than billing), moving to Workers Paid at $5 a month is accepted. Supabase, Render, Oracle and Netlify were rejected for pausing or expiring data or unclear costs, Firebase for requiring a paid plan for server code, and Vercel + Neon for cold-starting database and a separate image store. The cost is lock-in to the Workers runtime, so the stack must be JavaScript/TypeScript that runs there; the data stays plain SQLite and can be exported, but moving host means rewriting the server's platform bindings.
