# One Family per installation

Each installation of the app serves exactly one Family: there is a single account, no public sign-up, and no separation of data between families. This is a personal, non-commercial project, so open sign-up, invite-only multi-family accounts and per-family data isolation were rejected as security and maintenance cost with no user to pay for it. Moving to several Families later means a data migration (every record gains an owning Family) and adding isolation, so treat that as a new effort rather than a tweak.
