# One Family Password, set up with a one-time code

The Family signs in with a single shared Family Password; there are no per-Person accounts, no roles and no view-only devices. The account is created on a first-run setup screen protected by a one-time setup code from the hosting settings, so nobody who finds the address first can claim the calendar; the screen locks once the Family exists. Email is used only to recover the password (a single-use link valid for 1 hour) and to notify changes to the password or recovery email; a new setup code in the hosting settings remains the last resort. Magic-link-only, Google/Apple sign-in and passkeys were rejected for v1 as extra providers or setup for no gain in a single-account app; passkeys can be added later without changing this. Moving to per-Person accounts or roles later means new data ownership and permission checks throughout, so treat it as a new effort.
