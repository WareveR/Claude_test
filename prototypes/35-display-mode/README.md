# Prototype: Display Mode on a wall tablet (#35)

Throwaway UI prototype for [#35](https://github.com/WareveR/Claude_test/issues/35): what a landscape wall tablet in Display Mode shows. Open `index.html` in a browser. Sample data is the same as the #16 prototype, with today fixed at Wednesday 30 September 2026 at 14:10. The bar at the bottom (or the ← → keys) switches between three layouts.

**Verdict:** variant A ("Today + 7 days as a grid") with week navigation borrowed from variant B and the Person Filter added (version 3). B and C were dropped. The full verdict is in the [#35 resolution](https://github.com/WareveR/Claude_test/issues/35).

This branch is never merged; main keeps only the decision.
