# Prototype: calendar views (#16)

Throwaway UI prototype for [#16](https://github.com/WareveR/Claude_test/issues/16): what the day, week, month and year views show. Open `index.html` in a browser. Sample data is fixed, with today set to Wednesday 30 September 2026 at 14:10. The bar at the bottom (or the ← → keys) switches between four layouts.

**Verdict:** variant B ("Month on top + time grid") for every view. A and C were dropped; D (Display Mode) is being redesigned in [#35](https://github.com/WareveR/Claude_test/issues/35). The full verdict is in the [#16 resolution](https://github.com/WareveR/Claude_test/issues/16#issuecomment-5934219391).

This branch is never merged; main keeps only the decision.
